## Task 3 — Facebook share image preview + text format audit

**Files:** `src/components/layout/BaseLayout.astro`, `src/pages/suhba/[slug].astro`

**Root cause (Facebook):**
- `og:image:width`, `og:image:height`, and `og:image:type` meta tags are missing.
- Facebook's scraper requires explicit image dimensions to reliably render the preview card.

**What to change:**

**BaseLayout.astro** — add after existing `og:image` tag:
```html
<meta property="og:image:width"  content="1200" />
<meta property="og:image:height" content="630" />
<meta property="og:image:type"   content="image/jpeg" />
```

**[slug].astro — share text format:**

Update the share text passed to WhatsApp, Telegram, and Twitter to use the requested format:
```
[Title]

Read full suhba at: [url]
```

Build a new variable for the encoded share body:
```ts
const shareBody = encodeURIComponent(`${data.title}\n\nRead full suhba at: ${canonicalUrl}`);
```

- **WhatsApp** `href`: `https://wa.me/?text=${shareBody}`
- **Telegram** `href`: `https://t.me/share/url?url=${encodedUrl}&text=${shareBody}`
- **Twitter/X**: Twitter appends URL automatically; update `text` param to just `${encodedTitle}` (no change needed — current behaviour is fine)
- **Facebook, LinkedIn→Pinterest**: URL-only shares; preview comes from OG meta — no text param used
- **Email** body: update to `${data.title}\n\nRead full suhba at: ${canonicalUrl}` (removing quote from body to align with format; or keeping quote above if present)

**Status:** ✅ Complete

## Task 5 — CI: warn if speaker profile is missing (non-blocking)

**Files:** `scripts/check-speakers.mjs` (new), `.github/workflows/deploy.yml`

**What to add:**

**`scripts/check-speakers.mjs`** — new script:
- Reads all `.md` files in `src/content/discourses/`
- Extracts each `speaker` array entry from frontmatter (regex, no YAML parser)
- Converts each speaker name to a filename slug using the same `nameToSlug` logic as `speakers/[speaker].astro` (lowercase, NFD-strip diacritics, spaces→hyphens, strip non-alphanumeric)
- Checks if `src/data/speakers/${slug}.md` exists
- Prints `⚠️  No speaker profile found for "${name}" (expected: src/data/speakers/${slug}.md)` for each missing profile
- Always exits `0` — this is a warning only

**`deploy.yml` — Stage 1** — add a step after `Run Astro type check`:
```yaml
- name: Check speaker profiles (warning only)
  run: node scripts/check-speakers.mjs
  continue-on-error: true
```

(`continue-on-error: true` is belt-and-suspenders since the script exits 0, but makes the intent explicit.)

**Status:** ✅ Complete
